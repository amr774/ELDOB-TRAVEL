# Arabic typography

Noto Naskh Arabic variable font, weights 400–700, hosted locally.
Source: https://github.com/google/fonts/tree/main/ofl/notonaskharabic
License: OFL-NotoNaskhArabic.txt (SIL Open Font License).

Chosen as a Naskh-style approximation of the user's typography reference,
not a claim that it is the exact font shown in the screenshot.
Arabic UI uses 400 for body text, 600 for controls/subheadings and 700 for titles.
Responsive sizes are defined in src/arabic-type.css. English keeps its existing font.
